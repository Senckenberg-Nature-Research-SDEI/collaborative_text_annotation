# User Story: Chief Editor Zoological Journal

## 1. Persona

**Name:** Maria  
**Role:** Chief Editor, Zoological Journal

### Description

Maria is responsible for the scientific quality, visibility, and strategic development of a zoological journal specializing in insects. She promotes open access, open data, and FAIR biodiversity information. Her goal is to increase the discoverability, reuse, and scientific impact of the journal’s published type specimen information.
